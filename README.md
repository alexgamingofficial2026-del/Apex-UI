# Apex UI

Una librería de interfaz moderna, ligera y elegante para Roblox. Diseñada para ser fácil de usar, con un estilo oscuro y minimalista.

![Version](https://img.shields.io/badge/version-1.0.0-purple)
![License](https://img.shields.io/badge/license-MIT-blue)
![Roblox](https://img.shields.io/badge/roblox-compatible-red)

---

## ✨ Características

- 🎨 Diseño oscuro y elegante
- 🖱️ Ventana arrastrable y centrada por defecto
- 📑 Sistema de pestañas (Tabs)
- 🔘 Botones, Toggles, Sliders, Dropdowns
- 🎨 Colorpickers personalizables
- 📢 Sistema de notificaciones
- 💾 Guardado y carga de configuraciones
- ⚡ Ligera y rápida
